# 2026-05-27 변경사항

## 1. 콘티 곡 중복 추가 제한 제거

같은 곡을 한 콘티에 여러 번 추가할 수 있도록 제한 해제.

### 변경 파일

**`client/src/app/dashboard/contis/[id]/AddSongPanel.tsx`**
- `Props`에서 `addedSongIds: Set<string>` 제거
- `addedSongIds.has()` 기반의 `alreadyAdded` 로직 제거
- 곡 버튼의 `disabled` 처리 및 `opacity-40 cursor-not-allowed` 스타일 제거
- "추가됨" 텍스트 뱃지 제거

**`client/src/app/dashboard/contis/[id]/page.tsx`**
- `AddSongPanel`에 전달하던 `addedSongIds={new Set(conti.songs.map((cs) => cs.songId))}` prop 제거

### 백엔드
- `server/src/contis/contis.service.ts`의 `addSong()`은 원래부터 중복 제한 없음 — 프론트엔드만 수정으로 충분.
